# Betsy — static site

Plain HTML/CSS/JS. No build step, no dependencies.

    index.html      front page (watercolor portrait painted in)
    naps.html       nap menu: pick a nap, add-ons, printed receipt
    wardrobe.html   coat lookbook with "how it ends"
    assets/style.css
    assets/img/     all photos (webp)

## Put it online (free)
- Netlify Drop: open app.netlify.com/drop and drag this whole folder in.
- Or GitHub Pages / Cloudflare Pages: upload the folder as-is.

## Preview locally
Open index.html in a browser (fonts load from Google Fonts when online).
